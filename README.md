# Pesquisas de interesse público

Repositório público de Rafael B. Brotto com dossiês sobre temas de interesse público: casos institucionais, política, saúde pública, economia e o que mais merecer investigação cuidadosa.

## Como os dossiês são feitos

- **Só fontes publicadas.** Cada dossiê lista, ao final, todas as matérias, documentos e decisões consultadas, com link.
- **Neutralidade declarada.** Nenhum dossiê é peça de campanha nem toma partido. Quando as fontes divergem, a divergência fica anotada. Alegação é marcada como alegação; fato apurado, como fato.
- **Ressalvas explícitas.** Cada dossiê tem uma seção "Ressalvas de leitura" dizendo o que não está confirmado e de onde vem cada informação sensível (fonte anônima, coluna, documento oficial).
- **Data de corte.** Cada dossiê diz até que dia e hora o levantamento vale. O caso continua depois disso.
- **Auxílio de IA, revisão humana.** A compilação usa Claude (Anthropic) para varrer e organizar a imprensa; o texto final é revisado pelo autor antes de ser publicado.

Correções, fontes adicionais e contrapontos são bem-vindos por issue ou pull request.
